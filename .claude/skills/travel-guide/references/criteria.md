# 판단 기준과 서브에이전트 지시문

## 광고·AI 판별 (sources.py 에 구현)
- 광고: 원고료·소정의·협찬·체험단·지원받아·유료광고·파트너스·수수료 고지, 할인코드·쿠폰코드, 제휴/클룩/마이리얼트립/KKday/예매하기 등 예약 링크, "작성 조건 할인".
- 유튜브 광고: 설명란에 제작 지원·유료 광고·협찬·수수료·쿠폰·제휴·예약 링크.
- AI 의심: 템플릿 문구(결론부터, FAQ, 총정리, 알아보겠습니다, ✅📌1️⃣…)가 많고 1인칭 경험 표현(저희·먹었·다녀왔·ㅋㅋ…)이 거의 없는 글.
- 웹 출처: 여행사·예약플랫폼·호텔 블로그 제외. 트립어드바이저(이용자 후기)와 운영사 공식 사이트만 허용.

## 장소 정보 작성
- 깨끗한 후기의 문장만 근거로. 여러 가게를 다룬 글은 대상 가게 문단만 본다.
- 가격은 check.py 로 대조해 근거 없는 금액은 지운다. 못 찾으면 "가격 미확인(광고가 아닌 후기에서 확인 못 함)".
- 근거 후기가 0건인 장소는 목록에서 뺀다.

## 긍정·부정 평가 추출 (서브에이전트 지시문 요지)
입력 work/rev/batch{i}.json 의 모든 장소·출처에 대해:
- "pos": 그 장소에 대해 글쓴이가 좋았다고 한 점(40자 이내) 또는 "".
- "neg": 싫었던·아쉬웠던·비싼·붐빈·약했던 점 등(40자 이내) 또는 "". 가벼운 불만도 찾되 지어내지 않는다.
- 다른 가게·호텔·택시·다른 도시 이야기는 무시. 동명이점(같은 이름 다른 지점·다른 가게)은 둘 다 "".
- 출력 work/rev/out{i}.json: {"장소명": [{"i":1,"pos":"...","neg":"..."}]}. 임시파일은 고유 접두어(rev{i}_)를 쓰고 지운다.
- 부정 평가가 0인 장소는 "장소명 단점/아쉬운/솔직후기" 검색어로 후기를 더 모아 같은 방식으로 한 번 더 추출하고, 그래도 없으면 reviews.neg_note 에 "추가로 찾아봤지만 부정 평가를 찾지 못함(후기 수가 적음)".

## 대표 사진
- 간판·외관·대표 메뉴·내부처럼 그 장소임을 알 수 있는 사진. 셀카·사람 중심·호텔 객실·다른 가게·지도·메뉴판 캡처·제목 이미지 제외.
- 후보에 마땅한 사진이 없으면 null(사진 없음)이 틀린 사진보다 낫다.

## 홈페이지 확인 (서브에이전트 지시문 요지)
- 장소마다 웹 검색 1~2회. 업체 자체 홈페이지, 없으면 공식 인스타그램·페이스북·카카오톡 채널.
- 예약 플랫폼·트립어드바이저·구글맵·블로그·뉴스·다른 도시 동명 업체 제외. 체인은 해당 지점이 나오는 공식 사이트만.
- 불확실하면 넣지 않는다. URL 추측 금지.
- 블로그에 적힌 링크는 직접 접속해 확인: pf.kakao.com 은 존재하지 않으면 {"message":"Not Found"}, 인스타그램은 og:title 로 계정명 확인. 확인되면 "(접속 확인)", 접속 불가면 "(블로그 기재)".

## 구글맵 링크
- 블로그 본문의 구글맵 카드 줄("등록명 · 주소, Vietnam")에서 등록명+주소를 map_query 로. 관광지는 현지어 공식 지명.
- 등록명을 못 찾은 곳은 map_note 에 "검색 목록에서 선택" 또는 "주소 위치로 이동".

## 이동시간
- 거리 = 직선거리 × 1.3, 시간 = 대기 3분 + 거리 ÷ 평균 40km/h (5분 단위), 1km 미만은 도보 4.5km/h. 후기의 실제 이동 사례(예: 공항→남부 그랩 30~45분)와 맞는지 확인하고 config.travel 을 조정.

## 예약 페이지 (서브에이전트 지시문 요지)
- 장소마다 웹 검색 1~2회로 업체·운영사의 공식 온라인 예약/티켓 페이지만 찾는다(자체 사이트 예약 폼, 운영사 공식 티켓몰 예: booking.sunworld.vn, VinWonders 공식 티켓 페이지).
- Klook·KKday·마이리얼트립·트래블로카·아고다·Trip.com·GetYourGuide·GoWabi·여행사 등 재판매처는 제외. 업체가 직접 연결했는지 확인 안 된 Fresha 같은 페이지도 제외.
- 공원·해변·야시장·사원 등 공공장소는 검색하지 않는다.
- 후기 본문에서 여러 글에 반복해서 나온 카카오톡 ID·WhatsApp·오픈채팅 이름은 booking_note 로 넣는다(다른 가게 글에 섞여 나온 ID는 제외).
